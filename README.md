# CakeDine 🍰

A modern and responsive bakery website built using HTML, CSS, and JavaScript.

## Features
- Bakery product showcase
- Featured cakes and best sellers
- Responsive website design
- About, Menu, Services, and Contact sections

## Technologies
- HTML5
- CSS3
- JavaScript

## Project
CakeDine is a bakery website project designed to showcase delicious cakes and bakery products.
